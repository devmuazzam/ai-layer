## 1. Spec defects — what the spec missed

### SD-1 — REQ-03's ripple analysis named dead code as "the existing single gate"

- **Where:** `spec.md` REQ-03, **Ripple** field
- **What the executor needed to know:** which file actually gates the *Mark Available* / *Start Loadout* / *Off-load* button's disabled state, so REQ-03's new condition could be added to the right place.
- **What the spec said:** *"`isJobPrimaryActionDisabled` / `resolveJobPrimaryActionLabel` in `apps/web/.../loadout-workflow-utils.ts` are the existing single gate for the ... button's disabled state and label (only consumer found via `grep -rln "resolveJobPrimaryActionLabel\|isJobPrimaryActionDisabled" apps/web/src/features/dylen-dashboard --include='*.ts*'`: the same `loadout-workflow-utils.ts` file is where callers would extend the check)."*
- **What was decided instead, and by whom:** the decomposer re-ran the equivalent grep while writing `units.md` and found **zero callers outside the functions' own definition file** — VERIFIED (`grep -rn "isJobPrimaryActionDisabled(\|resolveJobPrimaryActionLabel(" apps/web/src --include='*.ts*'` → only the definitions, re-run independently for this reflection with the same result). `units.md`'s U3 slice-contents carries a correction: the button actually wired to the UI computes `primaryActionDisabled` inline, separately, in `dylen-job-card.tsx` and `dylen-job-shift-section.tsx`. The elaborator's own cited grep command, if its result had been read correctly, already showed this — a grep whose only matches are inside the cited file's own definition is evidence of **no** external caller, not confirmation that the file is where callers live. The elaborator recorded the opposite conclusion from the same evidence.
- **Was the decision right:** the *decomposer's* correction was right (confirmed live in the built code — `resolvePrimaryActionDisabled` in `shift-unassigned-summary.ts` is now called from both `dylen-job-card.tsx:116` and `dylen-job-shift-section.tsx:100`, a single shared helper, not two duplicated inline copies). The *elaborator's* original citation was wrong.
- **Cost:** one same-day correction pass inside `units.md` (documented inline as "**REQ-03 — correction to the spec's named ripple**"); no rework of shipped code, because the decomposer caught it before the executor built against the wrong file. Caught by the loop's own next stage, not by review or production.
- **Class:** `stale-reference`
- **Fix:** see R1.
