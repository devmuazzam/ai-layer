## CODE — most consequential first

1. **[P1] [INFERRED] Apply session-version invalidation to notification WebSockets.** Changed `apps/api/src/strategy/access-token.strategy.ts:39–42` rejects prior token versions only through HTTP authentication. The separate `apps/api/src/usecase/notifications/notifications-ws-auth.service.ts:29–38` verifies the JWT signature/expiry and current account status, without checking the token's session version. After SMS reset advances a user from version 0 to version 1, an unexpired version-0 token can still establish a new `/notifications` connection. `apps/api/src/presentation/notifications/notifications.gateway.ts:37–49` joins that connection to the user's room, and `:80–88` sends full new notification payloads to it. Connections opened before reset also remain eligible: subscriptions trust cached identity (`:59–66`), and broadcasts do not revalidate authorization.

   This leaves spec REQ-04 and U2's immediate rejection of old access credentials incomplete. Apply the legacy-zero/current-version rule to socket authentication, and revoke or revalidate existing connections before they can receive post-reset data. Preserve the resetting device's current session. Include regression cases for both stale reconnection and a socket connected before reset.

   **Refutation:** `apps/api/src/guard/access-token.guard.ts:15–19` explicitly skips WebSocket contexts. The gateway directly calls its separate validator, so HTTP and refresh rejection cannot protect it. `jwt.verify` does not compare a custom claim with the database. Web sockets send auth cookies (`apps/web/src/lib/socket/create-socket.ts:40–43`) and notification handling consumes the delivered payload; eventual HTTP failure on the client is insufficient. This is incomplete delivery of the new reset requirement, not a claim that the PR introduced the old separate validator. No runtime reproduction was executed.

No other concrete code defect survived this review. The local socket fix's presence does not refute the finding against the fetched PR head.
