# City permit reference — Adelanto to Los Alamitos

**What this is.** One row per permitting jurisdiction, transcribed from TCG dispatch's per-city
Word notes in the 2026-09-04 Project Repository drop. Continues in
[city-permit-reference-m-z.md](city-permit-reference-m-z.md). The cross-city patterns — channels,
annuals, fees, the Friday closures, stacked-permit jurisdictions — are summarised in
[permit-acquisition-process.md](permit-acquisition-process.md).

**Read this as a snapshot of dispatch's working notes, not as verified fact.** Several notes are
years old, several contradict the lead-time tables (see
[permit-lead-times.md](permit-lead-times.md)), and every field below is only what its note says.
Where a note is silent — most are silent about fees, most are silent about annuals — the cell is
`—`, which means *not stated*, never *no*.

**Credentials.** Where a jurisdiction uses a portal, the note usually records the live username,
password and security-question answer. Those are marked
`[portal credentials in the source file — deliberately not copied]` and were not transcribed.
The source path for every row is `__CITY_PERMIT/copy of all files/<City>/`.

## Source

`3.1.1_MODULE-CRM-SALES-QUOTES/__CITY_PERMIT/copy of all files/<City>/<file>.docx` — one Word
note per jurisdiction, `.docx` → pandoc GFM, read through the pre-combined digest
`SCRATCH/city-permits-combined.txt`. Sizes range from 75 bytes to 5 KB. `Brea/Brea Master.doc` is
not a note but the city's blank wide-load permit form; its restrictions are folded into the Brea
row. `Fontana/Document.docx` and `Riverside City/Document.docx` converted to **empty files** and
contribute nothing.
