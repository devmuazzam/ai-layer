# Flagged entries: payroll corrects them, per employee, any time; rest runs from rounded paid time

**Why this is a second note and not an edit of the first.** The first 2026-09-29 note records her
first reply, and it was committed and cited before this one arrived. This is a separate written
statement answering a separate set of questions. It also carries a pay rule (clause 5), which needs
a citable source of its own. Rewriting the first note would lose the record of what was open between
the two replies.

## The exchange

Syed Haris asked, in this order:

1. Who corrects a flagged entry? Does payroll edit ticket times, boom and lunches directly, or just
   see the flag and contact the crew?
2. Who is the Payroll Admin? Should both roles get every flag, and can either one fix it?
3. Editing a shared time like Start Work or End Job changes hours for everyone on the ticket. Is
   that OK, or should a fix apply to one person only?
4. Which times should be changeable? All of them (Left Yard through End Job, plus lunches)?
5. A rounding example: a changed End Job moves the next day's 8-hour rest. Is rest measured from
   rounded or actual times?
6. Besides boom length, what else should flag an entry automatically?

Corrina Bustos, Teams, 2026-09-29, verbatim:

> "Payroll Admin/Manager adjusts
> 2. Right now the Payroll Administrator is Micaela Slykhuis. That needs to be able to be adjusted in
> the future in the event there are any changes. Yes, payroll admin and manager need to get all of
> the flags and be able to adjust.
> 3. individual
> 4. all times
> 5. the 8 hour gap should be computed from the time rounded time because that is the time the EE is
> paid. per union rule the 8 hour gap rule goes off of when the EE was last paid. so if the ee worked
> until 11pm but the WTL penalty adds another 30 minute penalty per the rule, their 8 hour gap would
> really start at 1130.
> 6. yes, overlapping jobs, under 8 hours rest, missing notes, invalid time entries, invalid long boom
> time entries, if time does not match the samsara."

## Decision

1. **Payroll corrects flagged entries itself.** The Payroll Admin and the Payroll Manager adjust the
   entry. Payroll does not only see the flag and hand it back to the crew.
2. **Payroll Administrator.**
   - Today the Payroll Administrator is **Micaela Slykhuis**.
   - Who holds it "needs to be able to be adjusted in the future". So it is an **assignable role,
     not a hardcoded person**.
   - **Both** the Payroll Admin and the Payroll Manager receive **all** flags, and **either** may
     adjust.
3. **A correction applies to the individual employee.** Correcting a shared time (Start Work, End
   Job) changes that one employee's hours, not the whole crew's.
4. **All times are editable** in a correction.
5. **Pay rule: the 8-hour rest gap is measured from the rounded, paid end time.**
   - The gap runs from the **rounded** time, *"because that is the time the EE is paid"*. Rounding
     is start down, end up, to 30 minutes, per
     [2026-08-24-payroll-time-rounding-method.md](2026-08-24-payroll-time-rounding-method.md) /
     PAY-020.
   - *"Per union rule the 8 hour gap rule goes off of **when the EE was last paid**."*
   - **Paid time includes the WTL penalty extension.** Her example: worked until 11:00 PM, and the
     WTL penalty adds 30 minutes, so the rest gap starts at **11:30 PM**, not 11:00 PM.
   - Her example ends on a half-hour, so rounding changes nothing in it. The 30 minutes come from
     the WTL penalty alone. **Rounding and WTL extension are two separate claims.**
6. **Auto-flag sources, in addition to boom range:**
   - overlapping jobs;
   - under 8 hours' rest;
   - missing notes;
   - invalid time entries;
   - invalid long-boom time entries;
   - time that does not match Samsara.
