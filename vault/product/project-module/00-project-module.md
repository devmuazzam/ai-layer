# EPIC: Project Module

The Project Module is the central workspace where Sales, Dispatch, Coordinators, and Accounting all come together. It manages the full journey from the moment a quotation is signed until the job is completed in the field.

This Module is planned to be developed In 3

## Stories Included

* Create and Track Projects
* Create and Manage Jobs
* Create & Manage Job Schedule

* Create and Approve Lift Plans ( Epic : Plan )
* Create and Approve Site Plans 
* Create and Track Permits for Each Asset
* Project Dashboard Overview
* Client Reviews and Signs Quotation \[ DocuSign \]
