# EPIC 2 —> Home Dashboard

## US-4 —> Dashboard view

### User Story

As a field employee, I want to view my dashboard and active ticket so that I can quickly continue my assigned work.

### Acceptance Criteria

* Dashboard displays active ticket.
* Dashboard displays completion progress.
* Dashboard retains workflow progress after application restart.
* Dashboard displays notifications.
* Dashboard displays certification alerts.
* Dashboard displays weather information.
* Dashboard displays employee performance information including Hours Worked, Safety and Compliance metrics.
* User can upload updated certifications from certification notifications.
* Uploaded certifications are submitted for review and approval.
