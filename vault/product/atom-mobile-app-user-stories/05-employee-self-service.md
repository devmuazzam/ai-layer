# EPIC 5 — Employee Self-Service

## US-20 — Profile, Past Jobs & Checklist History

### User Story

As a field employee, I want to access my profile and historical records so that I can review previous activity.

### Acceptance Criteria

* User can access Profile.
* User can access Certifications.
* User can access Labor information.
* User can view completed tickets.
* User can view checklist history
