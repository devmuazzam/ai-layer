# Atom Mobile Application

The Atom Mobile Application is designed to support field employees throughout the complete job lifecycle, from pre-trip inspection and travel to job execution, compliance verification, and final ticket submission.

The application provides a guided workflow that enables employees to complete operational, safety, payroll, and customer-signature requirements directly from their mobile devices while maintaining visibility for Dispatch, Operations, Safety, and Payroll teams.

### **Flow :**

Login / Authentication **→** Dashboard **→** View Assigned Ticket **→** Accept Ticket **→** Pre-Trip Inspection **→** Left Yard **→** Travel to Job Site **→** Arrive at Job Site **→** Customer First Signature / Authorization **→** JSA / Tailboard **→** Start Work **→** Build-Up **→** Build-Up Complete **→** Boom Pay Tracking **→** Lunch / Work Through Lunch (when applicable) → End Work → Break-Down **→** Break-Down Complete **→** Customer Final Signature **→** Left Job **→** Return Travel **→** Arrive Yard **→** Post-Trip Inspection **→** Compliance / Attestation **→** Labor & Unit Details **→** Review Ticket **→** Complete / Submit Ticket
