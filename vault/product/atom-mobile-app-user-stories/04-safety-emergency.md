# EPIC 4 — Safety & Emergency

## US-18 — Incident Reporting

### User Story

As a field employee, I want to report incidents during a ticket workflow so that Safety can be notified.

### Acceptance Criteria

* Incident Report action is available.
* Report is routed to Safety.
* User returns to the same workflow position after submission.

## US-19 — SOS Emergency Assistance

### User Story

As a field employee, I want quick access to emergency contacts so that I can obtain assistance when required.

### Acceptance Criteria

* SOS action is available during ticket processing.
* SOS provides Call 911 option.
* SOS provides Call Safety option.
* SOS provides Call Crane Superintendent option.
* Safety contact routes to the currently assigned on-call Safety representative.
* Nearest hospital information is displayed and supports calling and navigation actions.
* SOS activity is logged.
