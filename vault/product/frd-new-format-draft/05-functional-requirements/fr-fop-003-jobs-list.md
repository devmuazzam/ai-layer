### FR-FOP-003 — Jobs List

| Field | Detail |
| --- | --- |
| ID | FR-FOP-003 |
| Title | Jobs List |
| Workflow position | Previous: User opens Jobs from bottom navigation. Current: User views assigned tickets. Next: User opens ticket details. |
| Description | The Application must allow field users to view their current, upcoming, draft, and completed tickets. |
| Functional requirements | Show assigned tickets. Separate ticket statuses: Not Started, Pending Acceptance, Accepted, In Progress, Draft / Incomplete, Completed, Rejected. Allow users to collapse completed tickets. Show key ticket details in list view: Job number, Ticket number, Job date, Job site, Assigned role, Assigned unit, Current status. |
| Business rules | Users see only tickets assigned to them or tickets they are responsible for processing. Oiler may see shared Operator/Oiler responsibilities. Third Man and Laborer see only their own assigned ticket. |
| Acceptance criteria | User can identify active and upcoming tickets. User can distinguish incomplete from completed tickets. User can open a ticket from the list. |
| Priority | Must have |
