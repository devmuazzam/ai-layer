### FR-FOP-022 — Compliance Checklist

| Field | Detail |
| --- | --- |
| ID | FR-FOP-022 |
| Title | Compliance Checklist |
| Workflow position | Previous: User arrives back at yard. Current: User completes compliance checklist. Next: Labor detail submission. |
| Description | The Application must support post-job compliance checklist completion before ticket submission. |
| Functional requirements | Provide compliance checklist after Arrive Yard. Capture lunch/rest/break confirmation. Capture per diem/subsistence indicators where applicable. Support Long Sub / Short Sub checkbox inputs where applicable. Require employee acknowledgement/signature. |
| Business rules | Compliance checklist supports payroll and billing review. Per diem/subsistence indicators flow into payroll review. Employee acknowledgement is completed before ticket submission. |
| Acceptance criteria | Compliance checklist can be completed. Lunch/rest/break confirmation is captured. Per diem/subsistence flags are available for payroll. Employee acknowledgement is stored. |
| Priority | Must have |
