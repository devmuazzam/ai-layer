### FR-FOP-006 — Ticket Detail View

| Field | Detail |
| --- | --- |
| ID | FR-FOP-006 |
| Title | Ticket Detail View |
| Workflow position | Previous: Ticket is accepted or assigned. Current: User opens ticket detail. Next: User begins guided execution. |
| Description | The Application must show all ticket details required for field execution. |
| Functional requirements | Display: Salesperson, Job number, Ticket number, Job date, Job site address, Map link, Customer contact number, Ordered-by contact, Equipment required, Description of work, Team information, Assigned unit(s), Ticket comments, In-house notes, Lift information. Allow direct calling of contacts. Allow map handoff for navigation. Show current workflow status. |
| Business rules | Ticket details are read-only unless the workflow explicitly allows user entry. Contact links support quick field communication. Map link supports navigation handoff. |
| Acceptance criteria | User can view all job execution information. User can call contacts. User can open map directions. User can identify the next required workflow step. |
| Priority | Must have |
