### FR-FOP-033 — Certification Expiry Notification and Upload

| Field | Detail |
| --- | --- |
| ID | FR-FOP-033 |
| Title | Certification Expiry Notification and Upload |
| Workflow position | Previous: Certification is near expiry. Current: User receives alert and uploads renewal. Next: HR/admin reviews upload. |
| Description | The Application must notify users of expiring certifications and allow renewal upload with status tracking. |
| Functional requirements | Notify user before certification expiry per configured rules. Allow file/photo upload. Show upload status: Submitted, Under Review, Accepted, Rejected / Needs More Information. Show admin comments when additional action is required. |
| Business rules | Certification approval is not automatic. HR/admin review is outside this FRD but must receive the upload. User is notified when review status changes. |
| Acceptance criteria | User receives expiry alert. User can upload renewal. User can see review status. User can respond to rejection/comments. |
| Priority | Must have |
