### FR-FOP-036 — Field User Profile

| Field | Detail |
| --- | --- |
| ID | FR-FOP-036 |
| Title | Field User Profile |
| Workflow position | Previous: User opens Menu. Current: User views profile. |
| Description | The Application must allow field users to view their profile information including role, classification, and contact details. |
| Functional requirements | Show basic user information, assigned role(s), primary field role, eligible roles where applicable, union/classification information, and contact information. Show emergency contact information where permitted. |
| Business rules | Role eligibility affects ticket assignment and labor processing. A user may have multiple eligible roles but one primary role. Profile data may be sourced from HR/employee management systems. |
| Acceptance criteria | User can view profile. User can see field role/classification information. Profile supports downstream ticket and payroll behaviour. |
| Priority | Must have |
