### FR-FOP-014 — Start / End Lunch

| Field | Detail |
| --- | --- |
| ID | FR-FOP-014 |
| Title | Start / End Lunch |
| Workflow position | Previous: Lunch alert appears. Current: User records lunch. Next: User resumes work. |
| Description | The Application must allow users to record lunch using Start Lunch and End Lunch actions with timestamps. |
| Functional requirements | Provide Start Lunch and End Lunch actions. Capture timestamps for lunch start and end. Allow manual adjustment with reason where permitted. Store lunch duration. |
| Business rules | Lunch capture reduces manual comments. Lunch records support payroll and compliance validation. If lunch is not taken, user must follow work-through-lunch flow. |
| Acceptance criteria | User can start and end lunch. Lunch duration is calculated. Lunch record appears in compliance/labor summary. |
| Priority | Must have |
