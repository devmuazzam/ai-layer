### FR-FOP-040 — Audit Trail

| Field | Detail |
| --- | --- |
| ID | FR-FOP-040 |
| Title | Audit Trail |
| Applies to | All ticket and labor-sensitive actions. |
| Description | The Application must maintain a full audit trail for all critical field actions. Audit records are not editable by field users. |
| Functional requirements | Track user, timestamp, action, and changed data for every critical event. Track manual time edits and reason. Track signature captures. Track checklist completion and deficiencies. Track ticket status changes. |
| Business rules | Audit data supports payroll, billing, compliance, and dispute resolution. Audit records are not editable by field users. |
| Acceptance criteria | All critical actions are logged. Manual edits include reason. Audit record is available for review. |
| Priority | Must have |
