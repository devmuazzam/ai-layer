block. **The originals were deleted from the local machine after ingestion; this page is the
searchable record of what existed.** To find out what happened to a file, search its name in

for anything in the payroll folder, in [../payroll/source-manifest.md](../payroll/source-manifest.md).

inside a zip/7z within the zip. `dup #N` marks files that are byte-identical to every other file
carrying the same number (55 duplicate groups, 116 files) — TCG's SharePoint holds many copies of the same
document under different folders, and that is worth knowing before anyone "finds" a second
version. Sizes are the extracted sizes.

**Search tips.** `grep -n 'Permit Tracker' ` this file for a name; `grep -c '^| ' ` for the count;
the city-permit library is under `3.1.1_MODULE-CRM-SALES-QUOTES/__CITY_PERMIT/copy of all files/<City>/`.
