### FR-FOP-032 — View Certifications

| Field | Detail |
| --- | --- |
| ID | FR-FOP-032 |
| Title | View Certifications |
| Workflow position | Previous: User opens Menu or receives certification alert. Current: User views certifications. Next: User uploads renewal if required. |
| Description | The Application must allow field users to view their certifications and open them for job-site verification. |
| Functional requirements | Show user certifications with name, expiration date, and attached digital file where available. Allow user to open certification file. Show expiry status clearly. |
| Business rules | Certifications may be requested by customers on job sites. Certification files are role-secured. |
| Acceptance criteria | User can view certification list. User can open certification file. Expiring certifications are clearly marked. |
| Priority | Must have |
