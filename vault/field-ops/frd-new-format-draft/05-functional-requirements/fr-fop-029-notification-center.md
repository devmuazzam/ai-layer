### FR-FOP-029 — Notification Center

| Field | Detail |
| --- | --- |
| ID | FR-FOP-029 |
| Title | Notification Center |
| Workflow position | Previous: System generates alert, task, or update. Current: User views notification. Next: User takes required action. |
| Description | The Application must provide a notification center covering all operational alerts for field users. |
| Functional requirements | Show ticket assignment notifications. Show ticket reminders and incomplete ticket reminders. Show certification expiry alerts. Show task assignments. Show lunch alerts. Show urgent escalation updates where applicable. |
| Business rules | Notifications are actionable where possible. High-priority alerts are visually distinguishable from informational alerts. Notifications link directly to the relevant screen. |
| Acceptance criteria | User can view notifications. User can open relevant ticket/task/certification from notification. Urgent alerts are visually distinct. |
| Priority | Must have |
