### FR-FOP-035 — Labor History and Audit

| Field | Detail |
| --- | --- |
| ID | FR-FOP-035 |
| Title | Labor History and Audit |
| Workflow position | Previous: User has submitted labor records. Current: User reviews historical labor and modifications. |
| Description | The Application must allow field users to view their labor history and any modifications made by payroll or admin after submission. |
| Functional requirements | Show labor history by date range. Show total labor hours and submitted ticket labor. Show changes made by payroll/admin and indicate what was modified. |
| Business rules | Payroll/admin modifications must be visible to the employee. Historical records are filterable by date range. Labor transparency supports employee trust. |
| Acceptance criteria | User can view labor history. User can see modified records. User can filter by date range. |
| Priority | Must have |
