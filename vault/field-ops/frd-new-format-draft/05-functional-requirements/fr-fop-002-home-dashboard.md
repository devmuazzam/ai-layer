### FR-FOP-002 — Home Dashboard

| Field | Detail |
| --- | --- |
| ID | FR-FOP-002 |
| Title | Field Operations Home Dashboard |
| Workflow position | Previous: User opens the application. Current: User lands on Home. Next: User opens active ticket, pending task, notification, or secondary module. |
| Description | The Application must provide a Home dashboard focused on current operations. It is not a module grid — it is an operational status surface that tells the user what to do next. |
| Functional requirements | Show current active ticket if one exists. Show upcoming assigned tickets. Show pending actions, incomplete ticket items, and urgent notifications. Show certification alerts and assigned tasks. Show basic daily work summary where available. |
| Business rules | Active ticket actions appear above secondary information. Incomplete ticket actions remain visible until resolved. Alerts affecting payroll, billing, compliance, or job execution are prioritised. Home guides the user to the next required action. |
| Acceptance criteria | User can identify what they need to do next from Home. User can open an active ticket directly from Home. User can access pending certification, task, or incomplete ticket items from Home. Completed ticket items do not dominate the view. |
| Priority | Must have |
