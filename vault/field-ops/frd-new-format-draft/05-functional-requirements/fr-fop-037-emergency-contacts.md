### FR-FOP-037 — Emergency Contacts

| Field | Detail |
| --- | --- |
| ID | FR-FOP-037 |
| Title | Emergency Contacts |
| Workflow position | Previous: User encounters urgent field issue. Current: User accesses emergency contact list. Next: User calls relevant contact. |
| Description | The Application must provide quick access to emergency and operational contacts with one-tap calling. |
| Functional requirements | Provide emergency contact list including Dispatch, Maintenance, Yard, and Office where applicable. Allow one-tap calling. Allow categorisation of contacts by issue type. Contact list is configurable by admin. |
| Business rules | This feature provides quick contact access but does not replace formal escalation workflows. |
| Acceptance criteria | User can open emergency contacts. User can call a contact directly. Contacts are categorised or searchable. |
| Priority | Must have |
