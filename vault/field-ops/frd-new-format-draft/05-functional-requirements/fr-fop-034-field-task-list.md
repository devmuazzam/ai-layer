### FR-FOP-034 — Field Task List

| Field | Detail |
| --- | --- |
| ID | FR-FOP-034 |
| Title | Field Task List |
| Workflow position | Previous: Task is assigned to field user. Current: User views and completes task. Next: Completion reported back. |
| Description | The Application must allow field users to receive and complete assigned tasks separate from the ticket workflow. |
| Functional requirements | Show assigned tasks with title, description, assigner, due date, and status. Notify user when a new task is assigned. Allow task completion. Allow comments or attachments where required. |
| Business rules | Tasks may include certification actions, document uploads, equipment requests, or operational reminders. Tasks are separate from ticket workflow but may link to a ticket or asset. Overdue tasks are highlighted. |
| Acceptance criteria | User can view tasks. User can complete assigned task. User receives task notification. Overdue task is visible. |
| Priority | Must have |
