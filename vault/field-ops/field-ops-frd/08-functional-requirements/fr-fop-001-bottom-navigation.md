### FR-FOP-001 — Bottom Navigation

| Field | Detail |
| --- | --- |
| ID | FR-FOP-001 |
| Module | Navigation |
| Title | Bottom Navigation |
| Description | The Application shall provide a consistent bottom navigation experience that enables users to quickly access key mobile functions. |
| Functional requirements | The Application shall provide bottom navigation. The Application shall display navigation options based on user permissions. The Application shall support direct access to the Home Dashboard. The Application shall support direct access to Jobs. The Application shall support direct access to Notifications. The Application shall support direct access to the Menu. The Application shall visually indicate the currently selected navigation item. |
| Acceptance criteria | **AC-001** Given the user is authenticated, When the application is opened, Then the bottom navigation shall be displayed. **AC-002** Given a user selects a navigation option, When the selection occurs, Then the corresponding screen shall be opened. |
